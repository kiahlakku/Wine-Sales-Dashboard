# Wine Sales Dashboard

## Project Overview
This Power BI dashboard provides insights into wine sales performance across different countries, categories, and wine types.

## Features
- Sales by Country
- Sales by Category
- Sales by Wine Type
- Quantity Analysis
- Unit Price Analysis
- Interactive Filters
